# 🎓 Graduate Student Placement Dashboard

### 📌 Project Overview

The Graduate Student Placement Dashboard is an end-to-end data analysis and visualization project designed to analyze student placements, salary packages, degree performance, and company-wise hiring trends.
The dashboard helps stakeholders such as students, placement cells, and academic institutions make data-driven decisions.

#### 🎯 Objectives

Analyze placement status across different courses

Compare salary packages (LPA) by company, position, and city

Identify top recruiting companies

Understand the relationship between degree marks and placements

Visualize city-wise placement distribution

#### 🛠️ Tools & Technologies Used

Data Analysis: SQL (PostgreSQL)

Data Processing: Pandas, NumPy

Visualization: Power BI

Charts Used:

Donut Chart

Line Chart

Area Chart

Waterfall Chart

Bar Chart

Map Visualization

Version Control: Git & GitHub
